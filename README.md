## ✨ Зачем нужен установщик

Windows не показывает большинство флагов стран как цветные эмодзи: вместо 🇫🇮 и 🇩🇪 в Chrome могут появляться буквенные обозначения `FI` и `DE`. Сторонний шрифт решает проблему, но обычная установка Windows не всегда переключает основной emoji-шрифт для Chromium.

**Flag Emojis Windows Installer** предназначен для того, чтобы установить поддержку флагов и при необходимости вернуть исходный шрифт Microsoft, без команд PowerShell и ручного изменения реестра.

## ⚙️ Возможности

- **Установка в несколько кликов.** Один EXE, запрос прав администратора и понятный результат.
- **Флаги в браузерах.** Настраивает Windows для отображения флагов стран в Chrome, Edge и других браузерах на основе Chromium.
- **Сохранение оригинала.** Исходный шрифт Windows не перезаписывается и не удаляется.
- **Установка и удаление.** Можно повторно запустить установщик или вернуть прежние настройки при удалении.
- **Проверенная загрузка.** Скачивает шрифт из источника проекта и проверяет файл перед установкой.
- **Без лишних процессов.** Без автозапуска, телеметрии и принудительных обновлений.

## 🚀 Установка и удаление

**Установка**

1. Скачайте `FlagEmojisSetup-vx.x.x.exe` из [GitHub Releases](https://github.com/xPROMSx/flag-emojis-windows-installer/releases).
2. Запустите файл, подтвердите запрос Windows на права администратора и следуйте подсказкам установщика. Он самостоятельно скачает проверенный шрифт и настроит отображение флагов.
3. **Перезагрузите Windows**, чтобы изменения вступили в силу.

**Удаление**

Откройте **«Параметры → Приложения → Установленные приложения»**, найдите **Flag Emojis Windows Installer** и выберите **«Удалить»**. Программа восстановит прежний выбор шрифта и удалит собственные файлы, не затрагивая оригинальный шрифт Windows. После удаления **перезагрузите Windows**.

## 📚 Технические сведения

Первая версия ориентирована на **Windows 11** и браузеры на основе Chromium. Для установки системного шрифта потребуются права администратора и перезагрузка.

Этот репозиторий посвящён **установщику**, а не разработке новых эмодзи или сборке файла шрифта. Исходный проект шрифта, условия использования и обязательные уведомления об авторстве указаны в [NOTICE.md](NOTICE.md).

**Лицензия кода:** [MIT](LICENSE). Права на компоненты шрифта рассматриваются отдельно от лицензии установщика.
