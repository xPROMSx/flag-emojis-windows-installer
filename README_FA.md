## ✨ چرا این پروژه؟

Windows بیشتر پرچم کشورها را به‌شکل ایموجی رنگی نمایش نمی‌دهد و ممکن است Chrome به‌جای 🇫🇮 و 🇩🇪 کدهای `FI` و `DE` را نشان دهد. یک فونت اصلاح‌شده این مشکل را حل می‌کند، اما نصب عادی فونت در Windows همیشه برای مرورگرهای مبتنی بر Chromium کافی نیست.

**Flag Emojis Windows Installer** نمایش پرچم‌ها را بدون دستورات PowerShell یا تغییر دستی رجیستری فعال می‌کند و در صورت نیاز می‌توانید آن را حذف کنید.

## ⚙️ ویژگی‌ها

- **نصب با چند کلیک.** یک فایل نصب با مراحل روشن و ساده.
- **نمایش پرچم‌ها در مرورگر.** پشتیبانی از پرچم کشورها در Chrome، Edge و سایر مرورگرهای مبتنی بر Chromium.
- **حفظ فونت اصلی Windows.** فونت اصلی بازنویسی یا حذف نمی‌شود.
- **نصب و حذف آسان.** اجرای دوباره نصب‌کننده و بازگرداندن تنظیمات پیشین هنگام حذف.
- **دانلود بررسی‌شده.** دریافت فونت از پروژه اصلی و بررسی فایل پیش از نصب.
- **بدون سرویس اضافی.** بدون اجرای خودکار، جمع‌آوری داده یا به‌روزرسانی اجباری.

## 🚀 نصب و حذف

**نصب**

1. فایل `FlagEmojisSetup-vx.x.x.exe` را از [انتشارهای GitHub](https://github.com/xPROMSx/flag-emojis-windows-installer/releases) دانلود کنید.
2. فایل را اجرا کنید، درخواست دسترسی مدیر Windows را تأیید کنید و دستورالعمل‌های نصب را دنبال کنید. نصب‌کننده فونت بررسی‌شده را دریافت می‌کند و نمایش پرچم‌ها را به‌طور خودکار تنظیم می‌کند.
3. برای اعمال تغییرات، **Windows را راه‌اندازی مجدد کنید**.

**حذف نصب**

به **Settings ← Apps ← Installed apps** بروید، **Flag Emojis Windows Installer** را پیدا کنید و **Uninstall** را انتخاب کنید. برنامه تنظیمات قبلی فونت را بازمی‌گرداند و فایل‌های خودش را بدون تغییر فونت اصلی Windows حذف می‌کند. پس از حذف، **Windows را راه‌اندازی مجدد کنید**.

## 📚 اطلاعات فنی

نسخه کنونی برای **Windows 11** و مرورگرهای مبتنی بر Chromium طراحی شده است. دسترسی مدیر و راه‌اندازی مجدد سیستم لازم است.

این مخزن مربوط به **نصب‌کننده** است، نه ساخت ایموجی‌های جدید یا تولید فونت. اطلاعات پروژه اصلی و حقوق مؤلفان را در [NOTICE.md](NOTICE.md) بخوانید.
