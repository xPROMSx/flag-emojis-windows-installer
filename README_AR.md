## ✨ لماذا هذا المشروع؟

لا يعرض Windows معظم أعلام الدول كرموز تعبيرية ملوّنة، وقد يظهر في Chrome الرمز `FI` أو `DE` بدلًا من 🇫🇮 و🇩🇪. يمكن لخط معدّل معالجة ذلك، لكن تثبيته بالطريقة المعتادة في Windows لا يكفي دائمًا ليعمل في المتصفحات المبنية على Chromium.

يساعدك **Flag Emojis Windows Installer** على إظهار الأعلام دون أوامر PowerShell أو تعديل سجل Windows يدويًا، ويمكنك إزالته عند الحاجة.

## ⚙️ المميزات

- **التثبيت ببضع نقرات.** ملف تثبيت واحد وخطوات واضحة.
- **أعلام الدول في المتصفحات.** إظهار الأعلام في Chrome وEdge والمتصفحات الأخرى المبنية على Chromium.
- **الحفاظ على خط Windows الأصلي.** لا يُستبدل الخط الأصلي ولا يُحذف.
- **تثبيت وإزالة بسهولة.** يمكن إعادة تشغيل المُثبّت واستعادة الإعدادات السابقة عند الإزالة.
- **تنزيل موثوق.** تنزيل الخط من مشروعه الأصلي والتحقق من الملف قبل التثبيت.
- **دون خدمات إضافية.** لا تشغيل تلقائي أو جمع بيانات أو تحديثات إجبارية.

## 🚀 التثبيت والإزالة

**التثبيت**

1. نزّل الملف `FlagEmojisSetup-vx.x.x.exe` من [إصدارات GitHub](https://github.com/xPROMSx/flag-emojis-windows-installer/releases).
2. شغّل الملف، ووافق على طلب صلاحيات المسؤول في Windows، ثم اتبع تعليمات التثبيت. سيُنزّل المُثبّت الخط ويتحقق منه ويُعدّ عرض الأعلام تلقائيًا.
3. **أعِد تشغيل Windows** لتطبيق التغييرات.

**الإزالة**

افتح **الإعدادات ← التطبيقات ← التطبيقات المثبّتة**، وابحث عن **Flag Emojis Windows Installer** واختر **إلغاء التثبيت**. سيعيد البرنامج إعدادات الخط السابقة ويزيل ملفاته دون المساس بخط Windows الأصلي. **أعِد تشغيل Windows** بعد الإزالة.

## 📚 معلومات تقنية

المُثبّت مخصّص حاليًا لـ **Windows 11** والمتصفحات المبنية على Chromium. يتطلب صلاحيات المسؤول وإعادة التشغيل.

هذا المستودع مخصّص **لبرنامج التثبيت**، وليس لإنشاء رموز تعبيرية جديدة أو تطوير الخط. تجد المشروع الأصلي ومعلومات الحقوق والإسناد في [NOTICE.md](NOTICE.md).
