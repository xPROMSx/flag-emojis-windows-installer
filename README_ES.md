## ✨ ¿Por qué este proyecto?

Windows no muestra la mayoría de las banderas de países como emojis a color: Chrome puede mostrar códigos como `FI` y `DE` en lugar de 🇫🇮 y 🇩🇪. Una fuente modificada soluciona el problema, pero instalarla mediante Windows no siempre basta para los navegadores basados en Chromium.

**Flag Emojis Windows Installer** permite mostrar las banderas sin comandos de PowerShell ni cambios manuales en el registro. Y puedes desinstalarlo cuando quieras.

## ⚙️ Características

- **Instalación en pocos clics.** Un solo archivo con instrucciones sencillas.
- **Banderas en el navegador.** Permite mostrarlas en Chrome, Edge y otros navegadores basados en Chromium.
- **Fuente original de Windows intacta.** Nunca se sobrescribe ni se elimina.
- **Instalación y desinstalación sencillas.** Puedes ejecutar el instalador de nuevo o restaurar la configuración anterior al desinstalar.
- **Descarga verificada.** Obtiene la fuente del proyecto original y comprueba el archivo antes de instalarlo.
- **Sin procesos innecesarios.** Sin servicios al inicio, telemetría ni actualizaciones forzadas.

## 🚀 Instalación y desinstalación

**Instalación**

1. Descarga `FlagEmojisSetup-vx.x.x.exe` desde [GitHub Releases](https://github.com/xPROMSx/flag-emojis-windows-installer/releases).
2. Ejecuta el archivo, acepta la solicitud de permisos de administrador de Windows y sigue las indicaciones. El instalador descarga una fuente verificada y configura las banderas automáticamente.
3. **Reinicia Windows** para aplicar los cambios.

**Desinstalación**

Abre **Configuración → Aplicaciones → Aplicaciones instaladas**, busca **Flag Emojis Windows Installer** y selecciona **Desinstalar**. El programa restaura la configuración anterior de fuentes y elimina sus propios archivos sin modificar la fuente original de Windows. **Reinicia Windows** después de desinstalarlo.
